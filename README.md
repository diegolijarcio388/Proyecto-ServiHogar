ServiHogar — Vista de la aplicación (Swift)

Vista desarrollada en Swift para una aplicación de servicios del hogar.
Permite al cliente seguir un proceso completo para solicitar ayuda profesional:

    Elección del servicio del hogar.

    Selección del tipo de cita.

    Descripción del problema.

    Elección del profesional disponible.

    Valoración final del trabajo realizado.

 Características principales

    Flujo guiado paso a paso para solicitar un servicio.

    Interfaz clara y fácil de navegar.

    Selección de servicios del hogar (limpieza, fontanería, electricidad…).

    Elección del tipo de cita (urgente, programada, visita técnica…).

    Campo para describir el problema del cliente.

    Lista de profesionales disponibles para elegir.

    Pantalla final de valoración del servicio.
